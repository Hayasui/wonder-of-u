# wonder-of-u

本仓库是一个求援流程技能。名字取自《JoJo 的奇妙冒险》第八部的替身 Wonder of U，中文译作「奇迹于你」——够不着的事交给外面那位，成不成在它。

输入是一个本模型够不着的问题：需要更宽的世界知识、需要联网核实的来源、或需要一个独立于自己的第二判断。输出是一份给外部大模型的英文求援件，整段可复制，加上取回之后的核对与并入说明。

说一句「找外援」「问外部模型」，或者直接报「wonder of u」「奇迹于你」，就把这个技能叫起来。技能在动手之前先过三问：这件事要的东西我拿不到吗，我的答案会影响到交付物吗，用户允许吗。三问全过才写件。件写完放项目目录，由用户转交；取回后先用脚本核，再决定并入。

技能横在任何一条工作链之外，不占其中一环。写件与核对由它做，裁量与并入仍归用户。

用法从 `SKILL.md` 入手。两类件的骨架、列名清单与可直抄的英文句子在 `references/templates.md` 下。

## 许可

内部研究工具，按需自取。
